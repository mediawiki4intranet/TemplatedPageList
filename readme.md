# TemplatedPageList

TemplatedPageList — это расширение для MediaWiki, предназначенное для динамического построения списков страниц по сложным критериям (категории, пространства имён, префиксы, вложенность) с возможностью гибко шаблонизировать вывод.

## Основные возможности

1. **Тег `<subpagelist>` или `<templatedpagelist>` и парсер-функция `{{#templatedpagelist:}}`**
   Главная фича расширения. Позволяет сделать выборку страниц из базы данных и вывести их на страницу.
2. **AJAX-дерево подстраниц**
   Автоматически добавляет вниз статьи ссылку вида `Подстраницы (N) →`. При клике асинхронно подгружается разворачивающееся дерево всех подстраниц текущей статьи.
   - надо подумать, может перенести куда? раньше было рядом с категориями, в верхнем правом углу.
3. **Парсер-функция `{{#getsection}}`**
   Позволяет трансклюживать (вставлять) не всю страницу целиком, а только конкретную секцию по её номеру.

## Синтаксис `<subpagelist>`
Опции передаются построчно, в формате `ключ=значение`. Внутри тега работает стандартный парсинг MediaWiki (можно использовать другие шаблоны и магические слова).

### Выборка страниц (Фильтры)
* `namespace = Main|Talk` — ограничить поиск пространствами имён.
* `category = A|B` — включает страницы из категории A ИЛИ B. Если указать несколько строк `category = ...`, они будут объединены через логическое "И" (AND).
* `subcategory = C` — как `category`, но рекурсивно включает все подкатегории категории C.
* `notcategory = D` — исключить страницы, находящиеся в категории D.
* `notsubcategory = E` — исключить категорию E и все её подкатегории.
* `parent = P` — показать только подстраницы страницы P (эквивалентно `prefix = P/`).
* `prefix = P` — показать страницы, названия которых начинаются с P.
* `level = L` или `MIN..MAX` — фильтр по уровню вложенности (количеству слешей `/` в названии).
* `deepness = D` или `MIN..MAX` — уровень вложенности относительно `parent`.
* `ignore = P1|P2` — исключить страницы по SQL-шаблонам LIKE (где `_` — один любой символ, `%` — любая строка).
* `redirect = yes|no` — включать или нет страницы-перенаправления.

### Сортировка и лимиты
* `order = title asc` (или desc) — направление сортировки.
* `ordermethod = ...` — по какому полю сортировать:
  * `title` / `fullpagename` (Пространство + Название)
  * `pagename` (Только название)
  * `lastedit` (Дата последней правки)
  * `user` (Последний автор)
  * `creation` / `firstedit` (Дата создания)
  * `size` / `length` (Размер в байтах)
* `limit = N` — показать не более N страниц.
* `offset = M` — пропустить первые M страниц.

### Вывод (Форматирование)
* `showtotal = yes|no` — вывести сверху общее количество найденных страниц.
* `output = simple | column | template` — формат вывода:
  * `simple`: Обычный маркированный список (ul/li).
  * `column`: Вывод в 3 колонки (как на стандартных страницах категорий MediaWiki).
  * `template`: Кастомный вывод через сторонний шаблон.
* `template = TplName` — если `output = template`, каждая найденная страница будет передана в шаблон `TplName`. Шаблону будут переданы следующие параметры:
  * `{{{index}}}` — порядковый номер (с 0).
  * `{{{number}}}` — порядковый номер (с 1).
  * `{{{odd}}}` — нечетная ли строка (1 или 0).
  * `{{{title}}}` — полное название найденной страницы.
  * `{{{title_rel}}}` — относительное название (если использовался параметр `parent` или `prefix`).
  * `{{{ns_N}}}` — флаг, где N — номер пространства имён.

## Настройка AJAX-дерева (в LocalSettings.php)

Поведение AJAX-дерева можно изменить через глобальные переменные (теперь через `$wgConfig`):
* `$wgSubpagelistAjaxNamespaces = [ 0 => true ];` — включает отображение AJAX-дерева в указанных пространствах имён (по умолчанию включено в основном пространстве (0)).
* `$wgSubpagelistAjaxDisableRE = '/regexp/';` — отключает отображение дерева для страниц, чьи названия совпадают с регулярным выражением.
